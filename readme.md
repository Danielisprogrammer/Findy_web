# 🌐 Findy Web

**Findy Web** est un projet web réalisé dans le cadre de ma formation **Full Stack Web Development 2025 (Udemy)**.  
Ce site a pour objectif d’aider les pères de famille à devenir des hommes responsables, attentifs et impliqués dans la gestion du foyer — aussi bien sur le plan matériel que personnel.

---

## 💡 Objectif du projet

Créer un site moderne et responsive en **HTML** et **CSS**, respectant la structure classique d’un site web professionnel avec plusieurs pages interconnectées.

Le projet met en avant la sensibilisation à la responsabilité parentale et familiale à travers un design simple et inspirant.

---

## 🧱 Structure du projet

Le site est composé de **4 pages principales** :
- `index.html` → Page d’accueil présentant la mission de Findy Web  
- `apply.html` → Page d’inscription ou d’engagement  
- `places.html` → Page d’informations ou de localisations  
- `about.html` → Page de présentation de l’initiative

Dossier complémentaire :
- `assets/` → Contient les **images** et les **feuilles de style (CSS)**  
  - `styles.css`  
  - `images/`
